OpenRay is a keyboard launcher for macOS, Windows and Linux. One hotkey, one search box, and
everything behind it: your applications, your clipboard history, your snippets, window
management, AI, and whatever you install.

![Root search](/openray/screenshots/root-search.svg)

## What ships in the box

Everything below except application search is an extension, running on the same runtime a
third-party extension uses.

| | |
| --- | --- |
| [Application search](/docs/features/applications) | Launch anything installed |
| [Calculator](/docs/features/calculator) | Answers as you type |
| [Clipboard History](/docs/features/clipboard-history) | Everything you have copied |
| [Snippets](/docs/features/snippets) | Reusable text, expanded as you type |
| [Quicklinks](/docs/features/quicklinks) | Links with a value dropped in |
| [Window Management](/docs/features/window-management) | 35 tiling presets |
| [Switch Windows](/docs/features/switch-windows) | Jump to any open window |
| [System Commands](/docs/features/system-commands) | Lock, sleep, volume, media |
| [Script Commands](/docs/features/script-commands) | Your own scripts as commands |
| [Emoji & Symbols](/docs/features/emoji) | Search by name, paste anywhere |
| [File Search](/docs/features/file-search) | Find files by name |
| [Screenshots](/docs/features/screenshots) | Search them by their text |
| [Notes](/docs/features/notes) | A floating markdown scratchpad |
| [Translate](/docs/features/translate) | 109 languages, no API key |
| [Menu Bar Search](/docs/features/menu-bar-search) | Trigger any menu item by name |
| [AI](/docs/features/ai) | Chat, commands, agents, MCP tools |
